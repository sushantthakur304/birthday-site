# 📸 Photos Folder for Toji & Mishtyy

You can place your photos directly in this folder (`/assets/photos/`), or you can simply click the **"Upload / Replace Photos 📷"** button right inside the website gallery!

### Recommended Photo Filenames:
- `school-1.jpg` (or `.png`) — School memory from 7th/6th standard days
- `couple-1.jpg` — 10th/9th standard or early relationship days
- `bikeride-1.jpg` — One of your favorite motorcycle rides together
- `college-1.jpg` — Toji starting college this year
- `funny-1.jpg` — Cute funny face or playful memory
- `special-1.jpg` — Special date or anniversary
- `random-1.jpg` — Sunset, casual hangout, ice cream date

> **Tip**: You can easily adjust photo links and captions in `js/config.js` or via the interactive photo manager in the gallery!
